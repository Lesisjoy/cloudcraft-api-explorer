CloudCraft Explorer

Una experiencia web que integra Vercel, dos APIs REST en AWS EC2 y una base de datos RDS MySQL. El frontend consume información real mediante proxies server-side, sin exponer la infraestructura privada al navegador.

Cómo funciona

Del navegador a la base de datos

Cada capa tiene una responsabilidad clara. Vercel protege las direcciones de origen y las APIs concentran el acceso a los datos.

01Navegador

Interfaz responsiva que solicita los recursos.

02Vercel

Sirve el frontend mediante HTTPS.

03Proxy server-side

Reenvía las solicitudes y controla errores.

04AWS EC2

Ejecuta las APIs REST de cada alumno.

05RDS MySQL

Centraliza y persiste la información.
